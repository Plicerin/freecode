## Tier I — identity: self-improvement (freecode's headline feature)
*The thesis: the model is frozen (a CLI can't fine-tune the API), so what compounds is the HARNESS. freecode watches its own work and proposes durable, inspectable, consented artifacts that make the next session faster/cheaper/more correct. It's the only feature whose value GROWS with use (a moat that deepens), and it's one a model vendor structurally won't build (it catalogues the model's recurring mistakes as files). freecode is uniquely positioned because it already has the three required substrates: the **activity log** (observation), **skills/rules** (the artifact format), and the **verify gate + provenance ledger** (measurement).*

**The line between this and "just another memory feature":** a memory feature *remembers*; self-improvement *measures whether remembering helped and prunes what didn't*. Four invariants keep it honest: (1) evidence before promotion, (2) a measurement, (3) decay of artifacts that don't fire/help, (4) consent + legibility — never silent; every artifact is a file shown with the evidence that justified it.

- [x] **Phase 1 — analyzer + propose-and-confirm** (`src/agent/self-improve.ts`, `/learn`, tested): reads this session's transcript + a recent activity-log tail and proposes 0–N durable artifacts — a **rule** (appended to `FREECODE.md`, loaded every session) or a **skill** (`.freecode/skills/<name>.md`). LLM→JSON→Zod, evidence-gated, prefers zero proposals to weak ones. `/learn` shows candidates with their evidence; `/learn save <n|all>` writes the accepted ones (traversal-safe names, won't clobber). Nothing is ever written without consent.
- [x] **Phase 2 — the measurement loop** (`src/agent/learn-stats.ts`, `/learn stats`/`prune`, tested): every learned artifact carries a scorecard. **Fires** (a hard fact — the Skill tool records each load) drive `/learn stats`; never-fired artifacts old enough to judge become **decay** candidates that `/learn prune` removes (skill file + scorecard; rules drop the scorecard and point you at the FREECODE.md line). A **verify-first-try trend** (before vs. since you started teaching freecode) is parsed from the activity log and shown *labelled correlational* — we deliberately do NOT fabricate a precise "saved you N corrections" causal number we can't substantiate (the same honesty the verify gate enforces). 9 tests.
- [ ] **Phase 3 — proactive + targeted**: offer the proposal at natural moments (session end / after a correction) instead of on-demand; bias toward containing the model's *recurring* failure modes (the highest-value thing to learn), drawing on cross-session activity-log signal.

## Tier X — exploratory / parked (net-new, unscheduled)
*Captured, not committed. Premature until the foundations they lean on are exercised in production.*
- [ ] **Berzerker mode — distributed compute fan-out** — a render-farm for coding sub-agents: fan a *fan-out-shaped* job (broad multi-file edits, whole-repo review, N-candidate generation, a large migration) across every reachable model endpoint at once — local llama-server/ollama/lmstudio + LAN peers + Tailscale peers + optional cloud. Value is **throughput on parallelizable work**, not single-edit latency (one big local model beats round-tripping five weak boxes for a lone edit) — so the mode must *refuse* work that doesn't fan out. Not a from-scratch build: it's a multi-endpoint **worker-pool backend** for the already-shipped Workflow engine + `Agent` dispatch + concurrency cap + MRM throttle — each endpoint becomes a worker slot, the strongest endpoint coordinates (split → dispatch → aggregate). Hard parts: heterogeneous capability (tier endpoints by ctx size + model strength; weak boxes get grunt work, never the synthesis), per-endpoint health/timeout + graceful degradation (drop a dead node and **log it** — no silent caps), genuinely independent work-splitting, budget/policy (local-only / local+cloud / per-run cap), result attribution. **Depends on Local-endpoint discovery (Tier B)** — without it the pool is a hardcoded host list, the exact thing we're trying to kill. Parked until `/consult` is exercised in production and discovery exists.
